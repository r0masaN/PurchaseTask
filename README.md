# Веб-приложение для работы с базой данных  

## О проекте  
Это веб-интерфейс для работы с таблицами базы данных, поддерживающий стандартные операции CRUD (создание, чтение, обновление, удаление).  
Приложение включает возможность поиска, сортировки записей и удобный интерфейс для управления данными. 

## Основной функционал  
1. **CRUD-операции:**  
   - Создание новых записей.  
   - Просмотр существующих записей.  
   - Обновление данных.  
   - Удаление записей.  
2. **Расширенные функции:**  
   - Поиск записей по ключевым словам.  
   - Возрастающая/убывающая сортировка записей по различным параметрам.  
3. **Архитектура:**  
   - REST API для взаимодействия между фронтендом и бэкендом.  
   - Удобный интерфейс с использованием адаптивных компонентов из библиотеки **Consta**.  
4. **Интерфейс:**  
   - Интуитивно понятный дизайн для быстрого управления данными.  

## Технологии  
- **Backend:** Java, Spring Boot.  
- **Frontend:** TypeScript, Vue.js, Consta.

## Системные требования  
- Современный браузер для работы с клиентской частью.
